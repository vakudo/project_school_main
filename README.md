# ProdLog – трекер оборудования

Небольшое демо-приложение на Flask для учёта оборудования. Интерфейс (templates + static) реализует список техники, фильтры, модальные окна для заявок в сервис и экспорт, а также тёмную/светлую тему. Бэкенд хранит сессию пользователя в cookies и работает без базы данных – данные о технике живут в памяти браузера (JS).

## Возможности
- Авторизация по заранее заданным аккаунтам (см. ниже).
- Просмотр, добавление и фильтрация карточек оборудования прямо из браузера.
- Быстрое создание сервисных заявок и отметок о проблемах через модальные формы.
- Экспорт списка в CSV/Excel (frontend-заготовка).
- Переключение темы (light/dark) с сохранением в localStorage.

## Запуск локально
Требуется Python 3.11+ и pip.

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt

# (необязательно) свой ключ для сессий
set SECRET_KEY=change-me

python app.py
```

Приложение поднимется на `http://localhost:5000`.

## Аккаунты по умолчанию
- `admin@example.com` / `admin123`
- `techlead@example.com` / `techlead123`

## Структура
- `app.py` – Flask-приложение и маршруты авторизации.
- `templates/` – HTML-шаблоны (login, основной экран).
- `static/style.css` – стили и базовые компоненты интерфейса.

## Полезно знать
- Данные о технике не сохраняются на сервере – это статическая витрина UI.
- Для продакшена обязательно задайте переменную `SECRET_KEY` и проксируйте через продакшн-сервер (gunicorn/uwsgi + reverse proxy).
